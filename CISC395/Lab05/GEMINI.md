# CISC395 Lab 05: AI-Assisted Development & Data Analysis

This project is a laboratory environment designed to explore AI's capabilities in software development, debugging, data manipulation, and document processing.

## Project Structure

- **`code/`**: Contains Python scripts.
  - `calculator.py`: Basic mathematical operations.
  - `buggy_sort.py`: Contains intentional bugs in sorting and searching algorithms for AI debugging exercises.
- **`data/`**: Project data files.
  - `student_grades.csv`: A dataset of student marks for Lab 1-4, Midterm, and Final exams, including calculated grades.
- **`messy/`**: A collection of poorly named files intended for organization and cleanup tasks.
- **`papers/`**: Academic and technical documents.
  - `1706.03762v7.pdf`: "Attention is All You Need" paper for summarization tasks.
  - `README.md`: Instructions for paper-related prompts.

## Core Mandates & Guidelines

### 1. Debugging Workflow
When addressing issues in `code/buggy_sort.py`, the AI should:
- Identify and explain the specific logical error in each function.
- Provide a corrected version of the function.
- Add test cases to verify the fix.

### 2. Data Processing
For `data/student_grades.csv`:
- Prefer standard Python (or `pandas` if available in the environment) for analysis.
- Focus on insights like average performance, grade distributions, or identifying students who need support.

### 3. File Organization
When managing the `messy/` directory:
- Propose a logical renaming and folder structure before moving files.
- Group files by type (e.g., documents, scripts, data) or context (e.g., assignments, notes).

### 4. Technical Standards
- **Language**: Python 3.x.
- **Documentation**: Ensure all new or modified code includes clear docstrings.
- **Testing**: Prioritize verification through unit tests or execution logs.

## Current Objectives
- Fix all intentional bugs in `code/buggy_sort.py`.
- Summarize key points from the provided PDF paper.
- Cleanup and reorganize the `messy/` directory.
- Perform basic statistical analysis on `student_grades.csv`.
